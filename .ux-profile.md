# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Linear <!-- Linear | Stripe | Apple Native | Raycast | Notion | Custom -->
- **Notes:** Dark charcoal background (`#090C10`) with a single restrained emerald accent (`#34D399`). Sharp 1px borders, monochrome surfaces, Space Grotesk headings and Inter body text. Technical `api/…` section labels. GSAP reveals run once and respect `prefers-reduced-motion`. Colour tokens live in `app/globals.css`.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary (the sticky header's blur is allowed because it sits on a near-opaque background with a solid bottom border)
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

## Accessibility target

- **Level:** WCAG 2.1 AA <!-- WCAG 2.1 AAA | WCAG 2.1 AA -->
- **Contrast:** Normal text at least 4.5:1; large text, borders and UI boundaries at least 3:1 against the dark background.
- **Touch / focus:** Interactive targets at least 44×44px; refined, always-visible emerald focus rings on keyboard focus.

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal <!-- Utilitarian & Minimal | Warm & Humancentric | Opinionated & Direct -->
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Plain, specific statements about real work; let the projects speak. No hype words or unverifiable claims. Never publish client personal data (names, phone numbers, addresses, figures) in copy or screenshots.

## Icon library

- **Library:** Lucide <!-- Lucide | Heroicons | Phosphor | Tabler | Radix Icons | Remix Icon | Project SVG | None -->
- **Package / path:** `lucide-react`
- **Notes:** Use 15–17px icons inline with text; mark decorative icons `aria-hidden="true"`. Icon-only buttons need an accessible name.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
